1. 수강생 관리 앱 설치 (한 번만)

신청 명단 페이지를 홈 화면 앱으로 쓸 수 있게 바꿨습니다. 앱을 열 때마다 명단을 새로 불러오고, 로그인 유지를 켜면 비밀번호를 다시 넣지 않아도 됩니다.

아이폰 1. 사파리(Safari)에서 https://leetaeho.co.kr/ai-class/admin 을 엽니다. (카카오톡 안에서 열렸다면 오른쪽 아래 메뉴에서 'Safari로 열기') 2. 화면 아래쪽의 공유 버튼(네모에 위쪽 화살표)을 누릅니다. 3. 목록을 내려 '홈 화면에 추가'를 누릅니다. 4. 이름이 '수강생 관리'로 나오면 오른쪽 위 '추가'를 누릅니다. 5. 홈 화면에 생긴 'AI 수강생' 아이콘을 눌러 엽니다. 6. 관리 비밀번호를 넣고 '이 기기에서 로그인 유지'에 체크한 뒤 '불러오기'를 누릅니다. 안드로이드 1. 크롬(Chrome)에서 https://leetaeho.co.kr/ai-class/admin 을 엽니다. 2. 오른쪽 위 점 세 개 메뉴를 누릅니다. 3. '앱 설치' 또는 '홈 화면에 추가'를 누르고 '설치'를 누릅니다. 4. 홈 화면 아이콘으로 열어 비밀번호를 넣고 '이 기기에서 로그인 유지'에 체크한 뒤 '불러오기'를 누릅니다. 끝났는지 확인: 앱을 닫았다가 아이콘을 다시 눌렀을 때 비밀번호 없이 명단이 바로 나오면 됩니다. 위쪽 '새로 고침'으로 새 신청을 다시 불러오고, 기기를 남에게 빌려줄 때는 '로그아웃'을 누르십시오.

Claude 유료 구독 https://claude.ai 에서 가입하고 로그인합니다. https://claude.com/pricing 에서 Pro 또는 Max를 결제합니다. 교육에서 쓰는 Claude Code는 무료 요금제에서는 열리지 않습니다. 구독료는 교육비와 별도이고, Pro도 되지만 하루 종일 실습하면 사용 한도에 걸려 잠시 기다려야 할 수 있습니다. 확인: claude.ai 화면에 Pro 또는 Max가 보이면 끝입니다. 2. Claude 데스크톱 앱 https://claude.com/download 에서 맥은 Download for macOS, 윈도우는 Windows 쪽 Download를 누릅니다. 내려받은 파일로 설치하고, 1번 계정으로 로그인합니다. 확인: 앱 위쪽 Code 탭을 눌렀을 때 입력창이 나오면 끝입니다. 이 화면을 찍어 이 방에 올려 주십시오. 윈도우 노트북은 Git도 깔아 주십시오. https://git-scm.com/install/windows 에서 Click here to download를 눌러 내려받습니다. 설치 화면은 전부 기본값 그대로 Next를 누르고, 끝나면 Claude 앱을 껐다가 다시 켭니다. 3.

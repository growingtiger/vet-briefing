# KAHA 회원병원 실무 소식지

한국동물병원협회(KAHA) 정책기획위원회가 회원병원 수의사를 위해 발행하는 요일별 실무 소식지입니다.

- 공개 주소: `https://<GitHub Pages 도메인>/kaha/` (저장소 루트 사이트의 `/kaha/` 하위 경로)
- 특정 호 직접 링크: `/kaha/?d=2026-08-10`

## 요일별 테마

| 요일 | 테마 | 다루는 내용 예시 |
|---|---|---|
| 월 | 진료 가이드라인 | WSAVA·ISFM·AAHA 등 최신 가이드라인 핵심 요약 |
| 화 | 노무·인사 | 근로계약, 최저임금, 연차, 4대보험, 직원 관리 |
| 수 | 서식·양식 | 동의서, 안내문 등 복사해 바로 쓰는 표준 양식 |
| 목 | 경영·세무 | 진료비 게시, 부가세, 손익 관리, 청구 실무 |
| 금 | 법규·정책 | 수의사법·마약류관리법 등 규제 대응, 정책 동향 |

테마는 `kaha/index.html` 상단의 `THEMES` 배열에서 수정할 수 있습니다. 뷰어는 발행 날짜의 요일로 테마 배지를 자동 표시합니다.

## 발행 방법

1. `kaha/issues/YYYY-MM-DD.md` 파일을 작성합니다 (마크다운).
   - 첫 줄: `# [○요일 · 테마명] 제목`
   - 둘째 블록: 발행 정보 인용구(기존 호 형식 참고)
   - 말미에 출처와 면책 문구를 넣습니다.
2. **팩트체크(필수)**: 아래 「발행 전 팩트체크」 절차를 수행하고 `kaha/factcheck/YYYY-MM-DD.md`에 기록을 남깁니다. 팩트체크 기록이 없는 호는 발행하지 않습니다.
3. `kaha/archive.json`에 날짜를 추가하고 `latest`를 갱신합니다.
4. 커밋 & 푸시하면 GitHub Pages에 자동 반영됩니다.

## 발행 전 팩트체크 (필수 절차)

모든 호는 발행 전에 다음 검증을 거칩니다. 창간 주간 검증에서도 실제로 오류가 발견·정정되었습니다(케타민 마약류 분류, NIMS 보고 기한, 진료비 게시 항목 수 — 각 호의 factcheck 파일 참고).

**검증 대상**: 본문에 등장하는 모든 ①숫자·금액·날짜(최저임금, 시행일, 기한 등) ②법령상 의무·범위·벌칙 ③가이드라인 권고 내용 ④제도명·기관명.

**검증 원칙**

1. **1차 출처 우선**: 법령은 국가법령정보센터(law.go.kr), 정책은 소관 부처(농림축산식품부·고용노동부·식약처) 발표, 가이드라인은 발행기관 원문(WSAVA 등). 블로그·커뮤니티 글은 단독 근거로 쓰지 않습니다.
2. **최신성 확인**: 시행일·개정 이력이 있는 제도는 "지금(발행 시점) 기준"이 맞는지 확인합니다. (예: 진료비 게시 항목은 2024년 확대 후 2025년에 다시 20종으로 확대 — 구 기준 인용 주의)
3. **확실하지 않으면 싣지 않는다**: 검증 불가한 주장은 삭제하거나 "～로 알려져 있음, 원문 확인 필요"로 명시합니다. 조문 번호가 불확실하면 제도명으로만 씁니다.
4. **정정 기록**: 팩트체크 과정에서 고친 내용은 factcheck 파일의 「발행 전 정정 사항」에 남깁니다.

**기록 양식** (`kaha/factcheck/YYYY-MM-DD.md`)

```
# 팩트체크 기록 — YYYY-MM-DD (요일 · 테마)

검증일: YYYY-MM-DD · 검증 방법: (원문 대조 / 부처 발표 확인 등)

| # | 본문 주장 | 판정 | 근거 |
|---|---|---|---|
| 1 | ... | ✅ 확인 / ⚠️ 표현 수정 / ❌ 삭제 | 출처 링크 |

## 발행 전 정정 사항
- (없으면 "정정 없음"이라고 기록)
```

## 로고 (협회 공식 로고 적용됨)

협회에서 제공한 공식 로고 원본(AI)과 웹용 PNG가 `kaha/assets/`에 있습니다. 임의 제작 로고는 사용하지 않습니다.

- `kaha-logo.png` — 가로형(심볼+국문+영문), 뷰어 헤더·PDF 양식 머리에 사용
- `kaha-logo-vertical.png` — 세로형, 필요 시 표지·인쇄물용
- `kaha-logo-horizontal.ai` / `kaha-logo-vertical.ai` — 일러스트레이터 원본

## 양식 PDF

수요일 서식 호의 양식은 `kaha/forms/*.pdf`로 제공되어 소식지에서 바로 다운로드됩니다. 생성 스크립트는 reportlab + 나눔고딕(fonts-nanum)을 사용하며, 새 양식 추가 시 같은 방식으로 PDF를 만들어 `kaha/forms/`에 넣고 해당 호에 링크합니다.

- `surgery-anesthesia-consent.pdf` — 수술·마취 동의서 (수의사법 제13조의2 요건 반영)
- `pre-anesthesia-checklist.pdf` — 마취 전 평가·모니터링 체크리스트 (2020 AAHA 마취 가이드라인 기반)
- `nutrition-assessment-chart.pdf` — 영양 평가·BCS/MCS 기록지 (WSAVA 영양 가이드라인 기반)

## 자동 발행 (매 평일)

평일 오전 6시(KST)에 자동 실행되는 Routine이 그날 테마의 소식지를 생성·팩트체크·발행합니다. 이미 준비된 호가 있는 날은 재검증 후 발행만 합니다. 콘텐츠 방침: **WSAVA·AAHA 등 무료 공개 가이드라인을 우선 인용**하고, 월·수요일은 가이드라인 기반 내용을 우선 편성합니다.

## 콘텐츠 작성 원칙

- 병원에서 **그 주에 바로 실행할 수 있는 체크리스트**를 반드시 포함
- 법령·고시 인용 시 조문 번호보다 제도명 중심으로 쓰고, 국가법령정보센터(law.go.kr) 원문 확인을 안내
- 노무·세무·법률 내용에는 전문가 자문 권고 문구를 유지
- 진료 가이드라인은 원문 출처(저널·발행기관)를 명기
- 각 호 말미에 팩트체크 기록 위치(`kaha/factcheck/날짜.md`)를 명시

## 이메일·단체방 배포

정적 페이지 링크(`/kaha/?d=날짜`)를 회원병원 단체 채널이나 메일로 공유하는 방식을 기본으로 합니다. 추후 뉴스레터 메일 발송 자동화가 필요하면 issues 마크다운을 HTML 메일로 변환하는 스크립트를 추가할 수 있습니다.

# KAHA 회원병원 실무 소식지

한국동물병원협회(KAHA) 정책기획위원회가 회원병원 수의사를 위해 발행하는 요일별 실무 소식지입니다.

- 공개 주소: `https://<GitHub Pages 도메인>/kaha/` (저장소 루트 사이트의 `/kaha/` 하위 경로)
- 특정 호 직접 링크: `/kaha/?d=2026-08-10`

## 요일별 테마

| 요일 | 테마 | 다루는 내용 예시 |
|---|---|---|
| 월 | 진료 가이드라인 | WSAVA·ISFM·AAHA 등 최신 가이드라인 핵심 요약 |
| 화 | 노무·인사 | 근로계약, 최저임금, 연차, 4대보험, 직원 관리 |
| 수 | 서식·양식 | 동의서, 안내문 등 복사해 바로 쓰는 표준 양식 |
| 목 | 경영·세무 | 진료비 게시, 부가세, 손익 관리, 청구 실무 |
| 금 | 법규·정책 | 수의사법·마약류관리법 등 규제 대응, 정책 동향 |

테마는 `kaha/index.html` 상단의 `THEMES` 배열에서 수정할 수 있습니다. 뷰어는 발행 날짜의 요일로 테마 배지를 자동 표시합니다.

## 발행 방법

1. `kaha/issues/YYYY-MM-DD.md` 파일을 작성합니다 (마크다운).
   - 첫 줄: `# [○요일 · 테마명] 제목`
   - 둘째 블록: 발행 정보 인용구(기존 호 형식 참고)
   - 말미에 출처와 면책 문구를 넣습니다.
2. `kaha/archive.json`에 날짜를 추가하고 `latest`를 갱신합니다.
3. 커밋 & 푸시하면 GitHub Pages에 자동 반영됩니다.

## 로고

`kaha/assets/kaha-logo.svg`는 임시 제작한 플레이스홀더입니다. **협회 공식 로고 파일을 받아 같은 경로에 같은 파일명으로 교체**하면 뷰어에 바로 반영됩니다(SVG 권장, PNG 사용 시 `index.html`의 `img src` 확장자만 수정).

## 콘텐츠 작성 원칙

- 병원에서 **그 주에 바로 실행할 수 있는 체크리스트**를 반드시 포함
- 법령·고시 인용 시 조문 번호보다 제도명 중심으로 쓰고, 국가법령정보센터(law.go.kr) 원문 확인을 안내
- 노무·세무·법률 내용에는 전문가 자문 권고 문구를 유지
- 진료 가이드라인은 원문 출처(저널·발행기관)를 명기

## 이메일·단체방 배포

정적 페이지 링크(`/kaha/?d=날짜`)를 회원병원 단체 채널이나 메일로 공유하는 방식을 기본으로 합니다. 추후 뉴스레터 메일 발송 자동화가 필요하면 issues 마크다운을 HTML 메일로 변환하는 스크립트를 추가할 수 있습니다.
